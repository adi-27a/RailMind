# Hackathon demo script

The banner always says **DEMO / SIMULATION DATA**. Do not describe it as connected to Indian Railways.

1. Open **Dashboard**: explain `SEE → PREDICT → ACT` and live feed state.
2. Open **Live Map**: filter a route, enable weather/congestion, select a train marker and fit the route.
3. Open **Train Intelligence**: inspect train `12951`, including position, ETA, freshness and weather risk.
4. Open **Delay Predictor**: run a synthetic-development prediction and explain factors/calibration disclaimer.
5. Open **Weather**: show rainfall, visibility, severe-weather flag and forecast.
6. Open **AI Assistant**: ask “Where is train 12951?” then show backend tools, source and freshness.
7. Open **Operations**: filter alerts and explain affected assets/recommended action.
8. Open **Analytics**: explain backend-fed trends.
9. Open **System Health**: explain API, database, Redis, ML, provider and WebSocket checks.
10. Close with `ARCHITECTURE.md`: provider boundaries let an authorized source replace simulation safely.
